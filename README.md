# Yurt Simülatör

Türk üniversite hayatı temalı bir yaşam simülasyonu oyunu. Tek dosyalık (vanilla JS + HTML/CSS) bir tarayıcı oyunudur — kurulum gerektirmez.

## Oynamak

`index.html` dosyasını herhangi bir modern tarayıcıda açman yeterli. Sunucuya, derlemeye veya bağımlılığa ihtiyaç yok.

## Canlı sürüm (GitHub Pages)

Repo ayarlarından Pages açıldıysa şu adreste oynanabilir:

```
https://Onurra.github.io/yurtsim/
```

## Teknoloji

- Saf HTML / CSS / JavaScript (tek dosya: `index.html`)
- Harici bağımlılık yok (ikonlar için Tabler Icons CDN)
